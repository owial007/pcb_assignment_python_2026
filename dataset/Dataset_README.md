# Datasets Used

## `HBB_reference_CDS.fasta` 

This contains the reference sequence for the `HBB` protein

## `variant_cds_new.csv` 

This contains the variants for the provided `HBB` protein DNA sequence.

Note: If you are planning to give your own `.csv` file then please make use of the same format as used in the `variant_cds_new.csv`
